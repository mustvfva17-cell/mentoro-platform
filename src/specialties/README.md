# Specialty modules

Each directory is a centrally registered module. HTML modules use the shared
authenticated MENTORO state bridge and centralized Mentor Review workflow.
Registration does not make a template assignable: lifecycle and
`is_assignable` remain controlled by the reviewed template publication flow.

The central registry contains six specialties and six HTML runtime paths:
General Surgery, Medical Oncology, Cardiology, Neurology, Pediatrics, and
Anesthesia & Critical Care.

Anesthesia & Critical Care was ported from
`mentoro-anesthesia-critical-care-logbook-project-v1.zip` with 157 roadmap
items (69 Core, 61 Expanded, 27 Advanced), 17 groups, nine Patient Journey
prompts, five Clinical Interpretation prompts, and five emergency templates.

Do not copy standalone ZIPs wholesale. Preserve the shared cloud state and
mentor-review contracts, stable entry IDs, and read-only mentor mode. Clinical
exposure is not competence certification. Specialty-specific clinical content
must remain Draft until an appropriately qualified reviewer approves it.
